🌍 Travel Planner

A modern and user-friendly Travel Planner website that helps users organize trips by selecting destinations, travel dates, and budgets. The application generates a simple travel itinerary and stores trip information for future reference.

✨ Features

Enter travel destination

Select travel dates

Set trip budget

Generate travel itinerary

Save trip details using Local Storage

Responsive design for mobile and desktop

Modern and attractive user interface


🛠️ Technologies Used

HTML5

CSS3

JavaScript

Git & GitHub

Vercel (Deployment)


📂 Project Structure

travel-planner/ ├── index.html ├── style.css ├── script.js └── README.md

🚀 How to Run

1. Download or clone the repository.


2. Open the project folder in VS Code.


3. Open index.html in a browser or use Live Server.


4. Start planning your trips.
